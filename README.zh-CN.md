# Personal Resource Hub · 我的资源站

[English](README.md) · **简体中文**

> 把电脑变成自己的资源中心 + 学习助手：拖进文件自动归类，手机在同一 Wi-Fi 下直接访问；可选接入任意 OpenAI 兼容大模型，获得文件问答、错题分析、AI 制卡与复习排期。

一个跑在本机的个人资源站（Node.js + Express + 原生 ES Module 前端，无构建工具），适合学生和自学者整理资料、背背记记、备考复习。

## 功能

### 资源管理

- 拖拽文件或整个文件夹上传，按 **主题 + 类型（7 类）** 自动归类，并自动打标签（笔记 / 课件 / 作业 / 真题 / 年份 / 章节等）
- 卡片视图与列表视图、主题总览、收藏、最近浏览、搜索与筛选
- 网页收藏：电脑书签、iPhone 快捷指令一键收藏 B 站 / 小红书 / 微信 / Instagram 链接，自动抓取标题、简介与封面
- **批量操作**：主页与隐私空间支持多选，批量收藏、移动主题、加标签、移入隐私、删除

### 隐私空间

- 独立密码进入，内部界面与外部资源中心一致
- 外部聚焦搜索可以搜到内部文件，但打开前必须验证密码
- 进入后内容不再打码，可直接预览

### AI 助手（`/orbit.html`）

- 侧栏与主页悬浮球进入，支持闲聊、学习问答
- 可直接读取你的文件内容作答（文本 / PDF / Word / PPT / Excel / 图片，最多 3 个文件）
- 主动建议：结合你的资料与考试情况给出下一步建议，并会持续轮换更新
- 可选：上传后自动总结、AI 自动分类、AI 自动填写文件类型

### 记忆卡片（`/cards.html`）

- Anki 风格问答卡片：AI 一键制卡、手动增删改、按卡组筛选
- 卡片式复习：空格翻面，`1/2/3` 忘记 / 模糊 / 记住，间隔按熟练度递增
- 历史时间轴：按年份分组、按时期（单元）筛选，正反面翻转小卡复习，适合历史时间线记忆

### 考试中心（`/exam.html`）

- 考试倒计时、复习计划完成度、各科得分率与总分趋势、弱科优先级
- 自动排期：只在周末与法定假期排任务，弱科排得更多，考前沿用套卷与错题复盘
- 成绩分析：逐科记录得分 / 满分 / 班平均 / 排名，自动生成分析
- **错题本**：拍照上传，AI 逐题识别、自动拆分、只收录做错的题，给出答案、错因、建议与知识点
- **错题小卡复习**：全屏卡片翻面回忆，`1/2/3` 评分，评分写回「待巩固 / 已掌握」，忘记的题自动排到队尾

### 手机与离线

- iPhone 与电脑同一 Wi-Fi 直接使用，可「添加到主屏幕」当 App 打开
- PWA / Service Worker 离线缓存（需 HTTPS，可用 Tailscale 免费获得）
- 电脑关机时仍可浏览索引与已缓存文件；断网时的收藏与上传进入「手机暂存」，恢复后自动同步

## 快速开始

1. 安装 [Node.js](https://nodejs.org/)（18 以上，推荐 20/22/24）
2. 双击 `启动资源站.bat`，或在本目录执行：

```powershell
npm install
npm start
```

3. 终端会打印电脑地址和手机地址，并显示二维码：

```
电脑访问   http://localhost:5178
手机访问   http://192.168.x.x:5178
```

## 用手机访问

1. iPhone 与电脑连接同一个 Wi-Fi
2. 用相机扫描终端里的二维码，或手动输入手机地址
3. Safari 底部「分享」→「添加到主屏幕」，以后可像 App 一样打开

打不开时依次检查：

- Windows 首次启动会弹防火墙提示，选择「允许访问」，并勾选专用网络
- 手机和电脑是否在同一个 Wi-Fi（不是访客网络）
- 终端打印的 IP 是否变化（重新启动后以最新地址为准）
- 电脑是否休眠或关机（本方案需要电脑保持开机）

> 本服务默认没有访问密码，同一 Wi-Fi 下的其他人也可能打开。不要在公司、学校公共 Wi-Fi 等环境使用；隐私文件请放进「隐私空间」。

## 在 Android 平板 / 手机上本地运行（Termux）

不想依赖电脑时，可以把服务直接跑在 Android 设备上：

1. 从 [F-Droid](https://f-droid.org/packages/com.termux/) 安装 Termux（不要用 Google Play 版），需要开机自启再装 Termux:Boot
2. 打开 Termux，执行：

```bash
pkg install -y git
git clone https://github.com/luobutu19-rgb/personal-resource-hub.git ~/personal-resource-hub
cd ~/personal-resource-hub
bash scripts/termux-install.sh
```

3. 平板浏览器打开 `http://localhost:5178`；同一 Wi-Fi 的其他设备用 `http://平板IP:5178`
4. 保持后台运行：执行 `termux-wake-lock`，并在系统设置里把 Termux 的电池优化设为「不限制」
5. 开机自启：安装 Termux:Boot 后创建 `~/.termux/boot/resource-hub.sh`，内容为 `termux-wake-lock` 加 `cd ~/personal-resource-hub && npm start`

数据保存在 `~/personal-resource-hub/data`，与电脑上的数据互相独立；可以直接复制 `data/` 目录在设备间迁移。

## 自动整理是怎么工作的

**类型（7 类）**：图片、文档、视频、音频、压缩包、代码、其他，按扩展名判断。

**主题（自动识别，按优先级）**：

1. 拖入文件夹时，取第一层文件夹名（如 `高数/第三章/极限.pdf` → 主题「高数」）
2. 文件名关键词匹配（如「四级真题」「简历」「数据结构」）
3. 都没有命中时归入「未分类」，可在编辑里手动修改

**标签**：从文件名识别用途（笔记、课件、作业、真题、简历、截图、录音等），以及年份、章节（如「第3章」）。

磁盘上的实际结构：

```
data/
├─ db.json                 # 文件索引
├─ settings.json           # AI 设置与隐私空间凭据
└─ files/
   ├─ 高数/
   │  ├─ 文档/
   │  └─ 图片/
   └─ 英语/
```

想调整归类词表，编辑 `server/classifier.js` 顶部的 `TOPIC_RULES`、`TAG_RULES`，保存后重启即可。

## 可选：接入 AI

默认关闭，不配置也能完整使用。需要时在页面右上角「设置」里填写：

- 接口地址：任何 OpenAI 兼容接口，如 `https://api.deepseek.com`
- 模型：以服务商文档为准，如 `deepseek-chat`、`gpt-4o-mini`
- API Key（只保存在本机 `data/settings.json`，不会上传）

开启后可以：

- 文件预览里点「AI 总结」，为文本、PDF、Word / PPT / Excel 生成不超过 120 字的摘要；图片交给支持视觉的模型识别
- 网页收藏也能「AI 总结」：抓取标题、简介和正文并生成摘要
- 编辑面板点「AI 整理」，自动选择主题与类型、移动文件并按规范标题重命名
- 主题页「AI 总结主题」，汇总整个主题的重点与复习方向
- `Ctrl / ⌘ + K` 聚焦搜索，用一句话找资源（如「第三章极限的笔记」）
- AI 助手直接阅读文件内容回答问题
- 错题本拍照识别、逐题拆分与错因分析
- 开启「上传后自动总结」和「AI 自动分类 / 填写类型」

注意：Office 文档只提取文字，图片会编码后发送给 AI；视频、音频暂不支持内容总结。文本片段与文件清单会发送到你配置的 AI 服务，请自行确认隐私与费用。AI 不可用时，聚焦搜索会自动回退为本地关键词匹配。

## 手机一键收藏（B站 / 小红书 / 微信 / Instagram）

原理：用 iPhone「快捷指令」把分享链接发送到本机收藏接口，服务端自动抓取标题、简介和封面，存成资源卡片。不需要安装 App。

### 配置快捷指令

1. 手机与电脑连同一个 Wi-Fi，电脑上资源站保持运行
2. iPhone 打开「快捷指令」→ 新建快捷指令
3. 点右上角设置，开启 **「在共享表单中显示」**，接收类型勾选 **URL、文本**（需要分享 Safari 网页时可再勾选 Safari 网页）
4. 添加动作 **「获取 URL 内容」**：
   - URL：`http://192.168.x.x:5178/api/collect`（可在资源站「设置 → 手机一键收藏」里复制）
   - 方法：`POST`
   - 请求体：选择「文本」，内容选择「快捷指令输入」
   - 不需要手动设置请求头；服务端同时支持 `text/plain` 和 JSON（`{"text":"..."}`）
5. 命名为「收藏到资源站」并保存
6. 在小红书、B站、Instagram 点「分享」→ 更多 → 「收藏到资源站」

配置好后，在手机浏览器打开资源站「设置 → 手机一键收藏」，点「测试连接」，显示「服务正常」就说明手机能访问电脑。

微信文章：若分享菜单里没有快捷指令，点右上角「…」→ 复制链接，再运行快捷指令；或直接把链接粘贴到资源站的「上传 → 收藏网页链接」。

### 电脑浏览器书签

新建一个书签，地址填下面这一段（把地址中的 IP 换成你电脑的）：

```js
javascript:fetch('http://localhost:5178/api/collect',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({url:location.href,text:document.title})}).then(()=>alert('已收藏')).catch(e=>alert('收藏失败：'+e.message))
```

### 说明

- 收藏的是**链接卡片**（标题、简介、封面、原文地址），不会下载视频或原图
- Instagram、小红书有登录和反爬限制，可能抓不到标题/封面；链接仍会保存，可手动改标题或用「AI 整理」
- 默认会尝试按标题关键词归入已有主题，识别不到时放入「网络收藏」；类型显示为「其他」，卡片角标显示平台名
- 手机离开家里 Wi-Fi 后无法访问本机服务；可以用 Tailscale 之类的组网工具，把快捷指令里的地址换成电脑的 Tailscale IP

## 手机上传照片 / 截图

1. 手机与电脑连同一个 Wi-Fi，浏览器打开 `http://192.168.x.x:5178`
2. 点右上角上传按钮（绿色箭头）或右下角「+」
3. 选择「上传照片 / 截图」，会直接打开相册，可一次选多张
4. 上传后自动归入「图片」类型，主题按文件名关键词识别，识别不到就放在「未分类」，可在编辑里改或用 AI 整理

提示：iPhone 照片可能是 HEIC 格式，Safari 能预览，但 AI 总结暂不支持 HEIC；需要总结时用截图（PNG）或转成 JPEG。视频、音频请用「选择文件」上传。

## 记忆卡片（Anki 风格）

侧栏「记忆卡片」进入独立页面 `/cards.html`。

- **AI 一键制卡**：把笔记、错题、公式或一段课文粘贴到输入框，选择卡组和数量（5/8/12/20），点「AI 一键制卡」
- **手动添加 / 编辑**：点「手动添加」或卡片右侧的编辑按钮，修改正面、背面、卡组和标签
- **卡组**：生成或手动添加时填写卡组名即可新建，左侧按卡组筛选
- **复习**：点「开始复习」，优先复习到期卡片；点卡片或按空格翻面，再选「忘记 / 模糊 / 记住」
  - 忘记：10 分钟后再出现
  - 模糊：间隔小幅增加
  - 记住：间隔按熟练度递增（初始 2 天）
- 快捷键：`空格` 翻面，`1/2/3` 分别对应忘记/模糊/记住，`Esc` 退出
- 数据保存在 `data/cards.json`

### 历史时间轴（`/history.html`）

- 按年份分组排序，按时期（单元）筛选，支持搜索
- 记录历史事件与时间（如「1840年6月 鸦片战争爆发」）
- 小卡复习：正面看事件提示，翻面看具体时间与说明，评分后进入下一张
- 内置「人教版九年级下册历史」常考时间线，可按自己的教材增删

## 考试中心

侧栏「考试中心」进入 `/exam.html`，面向初三（语文、数学、英语、物理、化学、政治、历史、体育，总分 720），按考试日期和假期自动排复习，并记录成绩做逐科分析。

- **总览**：距目标考试天数、计划完成度、各科得分率、总分趋势、弱科优先级
- **复习计划**：只在周末与法定假期排任务（周末每天 3 个、假期 4 个，可在设置里调），上学日不排；得分率越低的科目排得越多；考前 14 天转为限时套卷与错题复盘，考前 3 天回归课本；可逐项勾选完成
- **成绩记录**：新增考试（中考 / 一模 / 二模 / 月考 / 周测），逐科填得分、满分、班级平均、排名和试卷备注，自动生成总分、最稳科目、需加强科目、与班平均差、最好名次
- **教辅安排**：内置常见教辅清单，生成计划时把训练指派到具体教辅，同科目多本轮流；可在设置里增删
- **下周五带回清单**：按下周末的训练自动列出要带回的教辅，勾选状态会保存
- **错题本**：
  - 拍照或从相册选图，AI 逐题识别、只收录做错的题，一张图多道题会自动拆成多条
  - 每条错题包含题目、正确答案、错因、练习建议、知识点标签
  - 支持按科目、状态（待巩固 / 已掌握）筛选，批量管理
  - **小卡复习**：全屏卡片，正面题干 + 照片，点卡片 3D 翻面看答案与错因；`1/2/3` 对应「忘记了 / 有点模糊 / 记住了」，评分实时写回状态，忘记的题排到队尾
- 数据保存在 `data/exams.json`、`data/mistakes.json`

## 离线使用与 Tailscale 远程访问

iPhone 的离线缓存（PWA / Service Worker）**必须走 HTTPS**，直接访问 `http://192.168.x.x:5178` 不会启用离线缓存。用免费的 Tailscale 提供 HTTPS 地址即可。

### 一次性配置

1. 电脑和手机都安装 Tailscale，登录同一个账号
2. 打开 Tailscale 管理后台 → DNS，开启 **HTTPS Certificates**
3. 电脑上执行（PowerShell 或 CMD）：

```powershell
tailscale serve --bg 5178
```

如果提示命令不支持，改用：

```powershell
tailscale serve --bg http://localhost:5178
```

Windows 如果提示找不到 `tailscale`，重启终端，或用完整路径：

```powershell
& "C:\Program Files\Tailscale\tailscale.exe" serve --bg 5178
```

4. 命令会给出一个 `https://你的电脑名.你的tailnet.ts.net` 地址
5. 手机连上 Tailscale（打开 VPN 开关），用 Safari 打开这个 https 地址

### 启用离线缓存

1. 在 https 地址下打开资源站 → 设置 → 「离线与远程访问」，确认显示 **已启用**
2. 「自动缓存文件」默认开启：每次打开资源站、切回前台或恢复联网时，会在后台自动缓存收藏、最近浏览和最新文件
3. 卡片左下角出现 **「已缓存」** 标记，表示这个文件已经存到手机
4. 想立刻缓存，可点「立即缓存收藏与最近文件」
5. Safari 分享 → **添加到主屏幕**

之后：

- 电脑开机时：打开即同步最新数据，手机在任何网络都能访问
- 电脑关机时：打开主屏幕图标，显示「离线模式」，可浏览资源索引、封面以及已缓存的文件
- 电脑重新开机：打开一次资源站，自动同步并更新缓存
- 单个超过 30MB 的文件不会缓存；自动缓存总量约 120MB

> Tailscale 是点对点组网，不需要自己买云服务器，数据仍然保存在你的电脑上。

### 手机暂存（离线保存）

电脑关机或连不上时：

- 收藏网页链接、上传照片/截图，会先存进手机的「手机暂存」队列
- 「手机暂存」面板立即显示这些内容，可以直接打开链接或查看图片
- 电脑开机并联网后，打开一次资源站会自动同步；也可以点面板里的「立即同步」
- 同步成功后进入正常分类，暂存列表清空

限制：暂存基于 IndexedDB，清除 Safari 网站数据会一起清掉；单个暂存文件上限 100MB。iOS 快捷指令仍需要电脑在线。

## 隐私与安全

- 所有文件与数据只保存在本机 `data/`，项目默认通过 `.gitignore` 排除，不会被提交到仓库
- AI 的 API Key 保存在 `data/settings.json`，请勿把 `data/` 目录分享给他人
- 隐私空间密码以加盐哈希保存，不存明文
- 服务无内置鉴权，仅建议在受信任的家庭网络或 Tailscale 组网内使用；如需公网访问，请自行加反向代理与身份验证

## 备份与迁移

- 备份：复制整个 `data/` 文件夹即可（包含所有文件、索引、主题总结、卡片、考试与错题数据）
- 迁移：复制项目文件夹（不含 `node_modules`）和 `data/`，在新电脑 `npm install` 后启动
- 恢复：把 `data/` 放回项目根目录，重启服务

## 常用命令

```powershell
npm start     # 启动（默认端口 5178，被占用会自动 +1）
npm run dev   # 开发模式，修改后端自动重启
```

## 目录说明

```
server/          后端：Express、归类规则、上传、AI、考试与错题、数据存储
public/          前端：页面、样式、脚本、图标、Service Worker
data/            你的文件和数据（运行时生成，不提交到仓库）

```

## 技术栈

- 后端：Node.js 18+、Express 5、Multer、pdf-parse、fflate、qrcode-terminal
- 前端：原生 HTML / CSS / ES Module，无框架、无构建步骤
- 存储：本地 JSON 文件 + 磁盘目录
- 可选：任意 OpenAI 兼容 Chat Completions 接口
